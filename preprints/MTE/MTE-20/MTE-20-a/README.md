# MTE-20-a · Divine Command and Joint Grounding

- **Family:** MTE-20 — Does God ground morality?
- **Type:** principal
- **Discipline:** Metaethics
- **Estimated length:** 3 pages
- **Formalized:** no

## Main result

No. Morality is jointly grounded in divine and non-divine facts (REL-09); divine commands confirm rather than create moral obligations.
