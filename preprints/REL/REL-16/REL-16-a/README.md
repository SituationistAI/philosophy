# REL-16-a · Against Divine Simplicity

- **Family:** REL-16 — Is divine simplicity coherent?
- **Type:** principal
- **Discipline:** Philosophy of Religion
- **Estimated length:** 3 pages
- **Formalized:** yes, see `lean/Philosophy/REL/REL_16.lean`

## Main result

No. A simple being cannot have contingent knowledge; since God knows contingent truths, the doctrine of divine simplicity must be abandoned.
