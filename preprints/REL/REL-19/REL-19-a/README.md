# REL-19-a · Timeless Omniscience and Indexical Knowledge

- **Family:** REL-19 — Is God in time?
- **Type:** principal
- **Discipline:** Philosophy of Religion
- **Estimated length:** 5 pages
- **Formalized:** yes, see `lean/Philosophy/REL/REL_19.lean`

## Main result

God is timeless. It follows that God lacks indexical knowledge of what time it is now, which is no defect in omniscience properly defined.
