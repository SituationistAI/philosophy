\begin{abstract}
\enquote{Pegasus does not exist} is true. If existence is a first-order property had by everything, as MET-24-a argues, the sentence cannot be true because some object, Pegasus, lacks existence. We derive from that conclusion a general account of true negative existentials. A sentence of the form \enquote{$t$ does not exist} in which $t$ refers is false; so every true negative existential either contains a description that nothing satisfies, or an empty name, or uses \enquote{exist} in a restricted sense. We state the truth conditions in each case. None requires a non-existent subject, and none requires a truthmaker beyond what there is and what there is not.
\end{abstract}

\section{The trichotomy}

By Proposition~4.1 of MET-24-a, everything exists: for every $x$, something is identical to $x$.

\begin{lemma}\label{l:false}
If a singular term $t$ refers and \enquote{exists} expresses the property of Definition~3.1 of MET-24-a, then \enquote{$t$ does not exist} is false.
\end{lemma}

\begin{proof}
If $t$ refers to $a$, the sentence says of $a$ that nothing is identical to it, and $a$ is identical to itself.
\end{proof}

\begin{corollary}[No non-existent subject]\label{c:trich}
Every true sentence of the form \enquote{$t$ does not exist} falls under one of three cases: (i) $t$ is a definite description that nothing satisfies; (ii) $t$ is a name that has no bearer; (iii) \enquote{exist} is used in a restricted sense, such as concrete or present existence. In no case is the sentence true because some object lacks existence.
\end{corollary}

\begin{proof}
By Lemma~\ref{l:false}, a true negative existential with unrestricted \enquote{exists} has a non-referring subject term, which is either a description or a name; otherwise \enquote{exists} is restricted. In cases (i) and (ii), there is no object for the sentence to be about; in case (iii), the object exists and lacks some other property.
\end{proof}

\section{Truth conditions}

\paragraph{(i) Descriptions.} \enquote{The present King of France does not exist} says that it is not the case that exactly one thing is a present King of France. On Russell's theory \citep{Russell1905}, which LNG-03 defends, the description is not a referring term, and the sentence is the negation of a quantified claim. It is true because nothing, or more than one thing, satisfies the description. \citet{Cartwright1960} set out the difficulties facing the rival view, on which a negative existential is about its subject and denies it existence; the quantificational reading avoids them.

\paragraph{(ii) Empty names.} \enquote{Vulcan does not exist}, said by an astronomer after the explanation of Mercury's perihelion, contains a name introduced to refer to a planet and refers to nothing. Since there is no object, the sentence does not express a singular proposition about one. Two accounts of what it does say are consistent with Corollary~\ref{c:trich}. On the first, it says that nothing is Vulcan, or that the name \enquote{Vulcan}, as introduced, has no bearer: the claim concerns a practice of naming and the world, not an object. On the second, developed by \citet[ch.~10]{Evans1982} and \citet{Kripke2013}, a speaker who uses an empty name engages in or alludes to a practice of pretended reference, and \enquote{Vulcan does not exist} is a statement made from outside the pretence, true because the pretence has no counterpart in reality. We need not choose. On either account, the truth of the sentence requires only that nothing be Vulcan.

\paragraph{(iii) Restricted existence.} \enquote{Sherlock Holmes does not exist} is true. LNG-14 holds that \enquote{Holmes} refers to an abstract artefact created by Conan Doyle, and that artefact exists. By Lemma~\ref{l:false}, the sentence is then false if \enquote{exist} is unrestricted. It is true on the reading on which it is normally asserted: there is no concrete person who is Holmes, that is, the character is not a real man. \enquote{Exist} here expresses concreteness, or reality as opposed to fiction, which the abstract artefact lacks. The same holds of \enquote{Socrates no longer exists}, in which \enquote{exists} means presence at the present time, and of \enquote{the number seven does not exist in space}. In each case, the subject exists and lacks a further property.

\section{Truth without truthmakers}

It may be objected that a true sentence must be made true by something, and that on the present account negative existentials have nothing to make them true. This is so, and it is not a defect. MET-16 argues that negative truths need no truthmakers: they are true because of what there is and what there is not, and truth supervenes on being. \enquote{Vulcan does not exist} is true because the world contains no planet inside Mercury's orbit answering to the astronomers' introduction of the name. Nothing need be added to the world to make it true, least of all a non-existent planet. The argument from the subject-predicate form of negative existentials to their having subjects, which motivated Meinong, fails at its first step: a sentence of that form need not have a referring subject term in order to be true, and the true negative existentials are exactly the cases in which it does not.
